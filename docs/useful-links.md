# 实用网址维护说明

实用网址页按当前校区显示链接，条目定义在 [UsefulLinksActivity.kt](../app/src/main/java/cn/limpu/hita/ui/links/UsefulLinksActivity.kt)，标题定义在 [strings.xml](../app/src/main/res/values/strings.xml)。点按条目打开网址，长按复制网址。三个校区分别维护自己的栏目列表。
