# HITA Android 体验与动效修复规格

**状态：本轮实施与验收依据。**依据 [审查报告](report.md)。目标是让用户从画面、反馈与返回行为判断「现在是什么状态、发生了什么、下一步能做什么」。动画不得承担正确性、排队或授权职责。范围是现有应用自有界面和系统交接；不重写架构、不照搬 iOS 样式，不改外部服务，不把未测推断写成已修复。

## 取舍与共用约束

- **采用：先修合法状态和操作归属，再归一化动效。** 保留 Fragment 容器与 Android 原生返回、许可、IME；Compose/View 各自使用平台能力，统一用户可见的类别而非引入全站播放器。只调转场快慢遮不住误写与假空状态；全量迁移 Compose、统一换皮成本高且会丢现有行为，不选。
- **一次操作、一个归属。** 日期/范围/目录/查询/会话变化后，仅当前身份的数据能被操作。同身份缓存可在更新或失败时继续显示且标明陈旧；异身份旧内容不得伪装成当前内容。异步写入区分未提交、提交中、已提交、已拒绝；服务无法确定写入结果时明确「结果待确认」，不可直接鼓励重发。只为存在该状态的功能建模，不建全局泛型状态机。
- **默认代判，破坏前明确。** 唯一安全目标自动选；取消或返回不产生数据写入。可逆的常用操作直接做并给原位撤销；不可逆、跨账号、对外披露给明确对象及影响。通知、更新、背景同步不抢夺正在编辑或阅读的焦点；真正关键公告另行排队。
- **验证输入。**用可控的本地数据、延迟/失败/乱序替身产生前提，不引入真实个人信息或向真实服务写测试记录。下列每条均要求可观察的终态和反例；实际结果及未覆盖范围记在 [报告 §7](report.md#7-本轮修复后的复测)。

## 验收项

### S-01
来源：[UX-01](report.md#ux-01)、[UX-04](report.md#ux-04)。**空态、可用入口和已选状态。**

- 新安装无课表时，今日/时间表显示「导入课表」「新建空课表」等能完成的入口，不显示空选择器。打开管理、取消导入、返回或重建均不增加课表数；导入或明确保存第一个本地表后自动选它，重启保持。已有表/组且先前范围仍有效，不替用户改掉它；手动空表能进正确周次。
- 无壁纸看不到移除项；有壁纸时移除只影响该壁纸，有结果反馈，无关页不渲染课表壁纸。只有当前范围存在合格教务表才提供教务版本入口；个人恢复使用独立入口。今日/时间表/待办/助手/资讯/更多的选中与未读不只靠颜色或小点；新增、回本周、卡片动作可用名称与焦点触达。

### S-02
来源：[UX-05](report.md#ux-05)、[UX-06](report.md#ux-06)、[UX-08](report.md#ux-08)。**退出与删除不得隐式丢数据。**

- 用同时登录两类账号、存在个人/教学/好友课表和历史的夹具，从资料、更多和抽屉分别退出指定账号：明确显示对象，在未确认前无更改；只退出指定会话，不删除本地个人课表、待办等内容、不向新账号暴露旧账号私有缓存；清除数据由独立的有说明操作触发。
- 管理/组合/详情高损失批量操作在确认前给名称和数量，明确是「删除本地」还是「隐藏教务」。取消及写失败前后记录数不变、选择可继续；连点确认只提交一次。个人单次删除成功后提供撤销和指定课表的删除历史，恢复冲突不覆盖；教学隐藏可单独取消隐藏，版本恢复仍有影响预览和校验。投影/好友/只读对象从今日、网格、冲突与详情均不得得到不同的写权限，存储层也拒绝越过约束的请求。

### S-03
来源：[UX-07](report.md#ux-07)。**事件表单：保存直到结果明确。** 等长、反向或缺失时间范围立即说明，并保留可预期位置的保存按钮；输入合法才可提交。测试保存拒绝、提交中连点、重建、成功各一次：拒绝保留原草稿，重复不多写；成功仅在持久化后退出，立即在正确日期和范围可见；返回脏表单有保留或放弃选项。

### S-04
来源：[UX-09](report.md#ux-09)。**口令披露由发送者选择。** 单表/多选/分组在复制或分享前显示范围、成员数与实际披露字段；新口令默认仅忙闲，完整版须明确选。对本地表和组合分别解码仅忙闲与完整的输出：忙闲不包含原课程名、地点或教师；完整包含明确同意的字段；取消无导出。ICS 明示格式包含的信息，不冒充忙闲口令、不改变现有分享协议。

### S-05
来源：[UX-11](report.md#ux-11)、[UX-12](report.md#ux-12)、[UX-21](report.md#ux-21)。**助手请求、草稿与确认按会话绑定。**

- A 发出写请求，切 B 后 A 才请求确认：B 无弹窗；回 A 才可处理同一仍有效请求。取消、过期、停止、删会话均不能留下可交互的旧确认；来自后台的合法回复只交付原会话；每个授权只执行一次。
- 空内容/忙态拒绝发送时文本、附件、光标不丢；会话间草稿和附件不串。附件真实上限与说明一致，单附件可换、可移除；取消选档不改变草稿。发送成功接纳后才消费输入；解析或模型失败可回到原输入重试，停止使该请求进入可解释终态，不能撤回已经提交的写入。删除失败显示未删除并保留可恢复的列表状态。
- 用至少 100 条会话消息、包含长 Markdown 的回复和多行输入测试：相关消息状态在本行更新而不换身份；用户离开底部不被拉回，有回到最新回复的入口。贴底阅读时随新内容走，输入栏、附件状态、导航栏/IME 不挡住最后一条或欢迎快捷项。

### S-06
来源：[UX-10](report.md#ux-10)。**待办的日期、计数与撤销一致。** 日期条说明选的是新增截止日期并显示该日计数；列表显示所有日期，切日不丢滚动和输入，「今天」可回去。两次快速完成、一次平台错误：撤销仍能精准恢复各自目标，状态/计数按持久化结果更新，不把操作失败说成完成。个人空且已连接平台未结束时显示更新中/缓存，不显示全局空；最后一个源成功无项才可显示完整空态，失败时有来源和重试。

### S-07
来源：[UX-02](report.md#ux-02)、[UX-19](report.md#ux-19)。**信息与认证不抢前台，返回只消费一次。**

- 注入普通公告、可选更新、资讯会话过期，同时用户正在编辑/读内容：原焦点和草稿不变；公告/升级可从入口重见；读过才标记已读。重大公告最多一条在前台排队显示，不与权限/确认叠。静默续期在成功、需要验证、网络中断或到达明确的超时边界后退出；只有显式选择才打开交互式登录，保留现有缓存。
- 对同一升级版本分别在展示前后重建、取消权限、允许权限、后台/恢复：首次未处理可再次交付，而已处理不会被恢复重放。继续安装只关联触发该权限的请求；浏览器分发直接打开浏览器，不为了访问页面请求 APK 安装许可。下载失败保留可恢复入口，不自动重试或安装。

### S-08
来源：[UX-15](report.md#ux-15)、[UX-16](report.md#ux-16)、[UX-17](report.md#ux-17)。**内容和操作同一个查询，空态只能来自成功。**

- 给 A 注入慢结果、切 B 后让 A 最后完成；覆盖周/范围、资源目录进退、教师/资源检索、课程筛选、实验室/图书馆刷新。最终标题、正文、可执行行、缓存键都属于 B。新查询可先保留旧画面作非交互过渡，不能用旧行在 B 写入或导航；同键刷新保留滚动锚点。
- 对课程资源、成绩、空教室、学分、考试、培养/目录和校园卡分别覆盖成功空、未登录/过期、首次失败、缓存失败、已选来源部分失败。状态和有效下一步可区分：登录、重试失败的键/阶段、调整缺失来源、继续读缓存。重试重复同一学期的课程页/学分前置请求也发出正确查询；无网/部分源失败不能被「没有找到」吞掉；过期账单仍可读并可显式续登。引入并发只为可独立显示的结果，不为状态切换额外发请求。

### S-09
来源：[UX-13](report.md#ux-13)、[UX-14](report.md#ux-14)。**外部写请求以预览或明确目标提交。** 课程贡献预览显示仓库及变动内容，预览与提交同一快照；改表单、目标仓库或重建后不能不经校验复用旧授权，无快照就回编辑并解释。静音舱创建/撤销、选课计划权限往返、待执行任务取消测试成功、失败、未知响应和连续点击：提交中保留上下文，无重复提交；未知结果先核对远端记录，而非默认失败或自动重试；返回精确闹钟设置时在仍有效的同一参数上继续确认。只读地区不会出现可提交动作。

### S-10
来源：[UX-18](report.md#ux-18)。**展开、阅读、搜索恢复原位置。** 教师主页与原结果相关的主要动作可见，不只靠长按；返回和旋转保持当前查询、结果和合理焦点。资讯系列、课程资料、历史版本按稳定 ID 保留展开偏好，图标与读屏状态同步；长列表内展开/折叠 10 次，原行仍可见且最终状态符合最后一次操作。WebView 内链接或重定向不由重组恢复成入口，Back 先退浏览历史再退界面。无缓存加载失败在原页有重试/退出，不当静默结束。

### S-11
来源：[UX-20](report.md#ux-20)。**配置生效与目标定位。** 两个同类桌面组件选择不同范围、背景，切应用范围后，固定组件保留所选，跟随组件更新，背景按选择渲染。冷/暖点击行均定位原事件和日期；过期或无效身份只到安全上下文并说明，不打开别的课。允许通知时，对下课前与下课时（到点、迟到 1 分钟、超过 2 分钟、重复 Worker、改时区）设定可测试窗口：两分钟内同事件同规则最多一条，超窗不补过去的课；点击进入正确课程，权限拒绝按现有语义无发送。闹钟和 Android 通知渠道仍由平台控制。

### S-12
来源：[UX-03](report.md#ux-03)、[UX-04](report.md#ux-04)、[UX-22](report.md#ux-22)、[UX-23](report.md#ux-23)。**同意图同动效，首要结果不等待动画。**

| 状态变化 | 倍率 1 下的设计上限 | 可观察验收 |
|---|---:|---|
| 按下/取消、勾选、数字或状态图标 | 立即反馈，强调 ≤120 ms | 不滚动数字，不重排整页；点击、键盘或辅助操作都更新同一状态。单纯图标、颜色、触觉不能是唯一反馈。 |
| 切 Tab、切范围、切日期或列表换内容 | 点击反馈立即，切换强调 ≤180 ms | 顶栏与正文同一目标。加载不人为等待；不为了频繁切换做两整屏退场/入场，不可交互的旧画面不可获焦。 |
| 有来源的展开/菜单、抽屉和模态层 | 应用自管开合 ≤240 ms | 布局留住触发位置；按返回从相同关系退出，焦点复位。系统供应的转场不叠应用转场；经典/玻璃等主题不改变抽屉的几何语义。 |
| 有效拖动、取消和释放后的收尾 | 拖动不设动画时长；释放收尾 ≤220 ms | 指针直接决定位置；取消不提交，收尾期间第二次手势或点击从当前画面接管；每次至多切一次，反向和宽度变化不突然跳页。 |

应用自管的非手势入场使用减速、退场加速；页签/微反馈用同一组参数，只有直接操纵需要保速度连续性的收尾用无反复振荡的弹簧。留住已验证的视图生命周期限制；壁纸退出只在仍属于课表时可淡化，切出当帧不得泄到其它 Tab。系统倍率 0 时，非手势位移/缩放、装饰循环及动画等待停止；跟手拖动仍可用，松手直接给出终态，用静态状态说明结果。倍率恢复不重复操作；触觉尊重系统设置。会话请求、保存或导航不能由 animation end 触发业务副作用。

### S-13
来源：[UX-04](report.md#ux-04)、[UX-21](report.md#ux-21)、[UX-23](report.md#ux-23)、[UX-23-B](report.md#ux-23-b)。**适配、无障碍和性能发布门。**

- 验收矩阵：可用窗口 320/411/600/864 dp、横屏/实分屏、字体 1.0/1.3/2.0 和深浅色；经典及玻璃组合全跑，赛博/深空覆盖动画开关，日映/波普/水墨检查一致性；IME、手势/三键、TalkBack、键盘/鼠标输入各一轮。受限宽度先保留状态文字和常用动作，其余可收纳；不裁重要标签，不让画面露出可操作性但点不到，触达区至少 48×48 dp，不与邻项重叠。鼠标悬停只是额外反馈，不能隐去名称或破坏触屏路径；列表内容可滚到安全区、焦点顺序与读序一致。键盘出现和宽度/主题变化不清草稿、选项、滚动锚点。
- **真机性能门（拟定，不是本轮结果）：** API ≥31 的 60 Hz 中档机及 90/120 Hz 机各一台；同机同刷新率、同温区/编译方式、用接近 Release 的可分析包，匹配数据和比较顺序。同一旅程至少 10 次，覆盖五 Tab 循环、10 次快速滑周、≥200 项待办滚动加勾选、≥100 条助手消息和长 Markdown 展开、经典/玻璃抽屉，另测装饰主题停留和倍率 0。用 [FrameTimingMetric](https://developer.android.com/topic/performance/benchmarking/macrobenchmark-metrics#frametimingmetric) 记录原始 JSON/trace、P95/P99 `frameOverrunMs` 和超时帧比例。各旅程 P95 ≤ 0 ms、P99 ≤ 一个本机帧预算、超时帧比例 ≤5%；相对同机基线不得上升超过 1 个百分点（不适用于无基线的新旅程）。报告基线、候选、帧数和采样条件；轨迹中发现整页白帧、明显剪切、重排、可操作旧页或触发被吞也失败。倍率 0 与静态停留不应由装饰持续触发帧。

模拟器上取得四个旅程的帧时长样本（[UX-23-B](report.md#ux-23-b)）；只能用于定位和设计同 AVD 的对照实验，不能替代真机数据。真机性能和三校区真实登录不作为本轮本地验收或后续合并的必过项，仍单独记录未测。详细实施顺序与检查入口见 [计划](plan.md)。
