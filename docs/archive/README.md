# 归档文档

这里存放**已完成、不再指导当前开发**的过程性记录：一次性审计、重构阶段的执行台账与交付报告。
它们保留下来是为了可追溯（当时的判断依据、实测数据、取舍理由），不是当前行为的说明。

**当前有效的功能说明在 [`docs/`](../) 根目录**；测试体系的现行约束在 [`docs/testing/`](../testing/)。

## 分类

| 目录 | 内容 | 时间 |
|---|---|---|
| [`refactor/`](refactor/) | 全仓优化的阶段审计、执行台账与交接记录（阶段 3/4/5、Agent 03 UI 重构） | 2026-10 ~ 2026-11 |
| [`audits/`](audits/) | 专项审计：CI/CD、数据层一致性、运行性能、安全与凭据存储 | 2026-10 ~ 2026-11 |
| [`testing/`](testing/) | 四层测试体系建设期的执行结果、基线报告、清理计划与自评 | 2026-11 |

## 使用约定

- 归档文档**不再随代码更新**。若其中的结论与当前代码冲突，以代码和 `docs/` 根目录的说明为准。
- 需要引用历史实测数据时可以链接到这里，但不要把归档内容当作现行规范。
- 新的过程性记录写完后，若已无指导价值，直接归入对应子目录，不要留在 `docs/` 根目录。
