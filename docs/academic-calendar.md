# 校历与课表标题

个人课表最后一节课不等于学期结束。顶部周次优先使用独立校历范围；未获取到校历时仍可显示课表范围内周次，但范围外只显示“非所选学期”，不宣称已放假。

## 官方来源

- 本部：https://en.hit.edu.cn/Links/list.htm 。解析公开 HTML 的周次、月份、合并单元格和明确的寒暑假行。
- 深圳：https://www.hitsz.edu.cn/ 首页“校历周历”。解析当前校历的学年、周次与每日日期，并校验周次连续和星期一致。
- 威海：https://jwc.hitwh.edu.cn/xlxz/list.htm 。读取校历文章中的 `pdfsrc`，使用项目已有 PDFBox 解析附件末尾的明确学期开始与寒暑假日期。

日期按北京时间处理，按 `BENBU`、`SHENZHEN`、`WEIHAI` 隔离。混合校区组合课表只有各校区都确认处于假期才显示假期。手动课表、缺少校区标识的旧课表不猜测所属校区。

缓存读取和网络读取均在 IO 线程，保留成功缓存；各校区独立记录成功时间，成功后每天刷新，失败后间隔至少 15 分钟重试，失败不清除已有校历。并发刷新直接跳过，不排队等待网络。解析日期不写入 Room，不改课程时间、课表起点、结束时间、导入快照和提醒范围。

## 已核对样例（2026-10-22）

- 本部秋季：https://en.hit.edu.cn/2026/0528/c11997a242425/page.htm
- 深圳秋季：https://www.hitsz.edu.cn/2025/1125/c87a18405/page.htm
- 威海秋季：https://jwc.hitwh.edu.cn/2026/0827/c3160a219383/page.htm

三份校历的秋季教学范围均为 2026-08-31 至 2027-01-10。每份独立解析，未共享日期常量。本部、威海另明确寒假为 2027-01-11 至 2027-02-21。

## 数据限制

深圳当前公开周历只有教学周，没有明确寒假结束日期；教务通知的完整校历 DOCX 下载需要验证码。当前不据此推断深圳寒假边界。待取得该校区明确寒假来源后再补充。

本部夏季学期与暑假合并在一张表中，不能仅凭七个周次认定这七周全是暑假。没有明确边界时不显示“假期”。未知年份不延用前一年日期。校历页面提示具体放假以学校办公室通知为准，个别学院安排也可能不同。

测试样例保留了对应官方表格/附件提取文本，验证跨月、跨年、周末、学期末考试周、校区隔离、未知范围与格式失败。威海 PDFBox 运行时解析仍需 Android 真机联网验证。
