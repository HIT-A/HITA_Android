# Android 使用统计 v2

此实现与 data-backend 的 `foreground_installs_v2` 配套，旧客户端仍走兼容接口。`app_version` 不决定口径；以事件 `schema_version=2`、`sdk_version=2` 区分。Debug 构建发送 `environment=test`，正式发布后才开始积累生产新版日活跃。

## 采集与发送

- 安装标识优先保留原 usage UUID，其次沿用旧 visit UUID，否则生成新 UUID。停止进程启动时的旧 visit 上报；不采集账号、学号、课表、成绩、关键词、对话、URL 或原始错误。
- 独立 Room 数据库保存完整不可变事件、同意开关代次、发送租约和本地质量计数。每条事件保留生成时版本和 UTC 时间。旧 SharedPreferences 队列按 event_id 迁移，缺失的生成时版本明确记为 legacy-unknown。
- 队列上限 2,000 条或 2 MiB，优先保留活跃与操作终态；超过七天过期。本地记录容量丢弃、过期、协议和传输失败计数。
- 每批最多 50 条，只有 ACK 中明确接受、重复或已知永久拒绝的 event_id 才出队。未知 2xx、HTML、未确认 ID 保留。413 拆批，429 遵守 Retry-After；401/403/404 延后重试。WorkManager 网络约束、退避和十五分钟兜底任务负责重试。
- 发送进程互斥与持久租约防止并发排空；进程突然结束后租约最多等待两分钟过期。关闭统计会取消在途请求、后台任务并清除旧代次事件；重新打开后旧 Worker 不能恢复发送关闭前的数据。
- 线程契约：同意开关代次与会话状态（session_id、last_seen、last_background）以进程内内存为唯一读取来源，主线程不再读写 SharedPreferences；落盘统一在 IO 协程内完成（`commit` 仅在后台线程）。因此开关切换的可见性立即可得，磁盘写失败只记录本地失败，不再抛到 UI 线程。代价是进程被系统杀死时可能丢失最后一次 `last_seen`；会话判定在写出前的同一决策内使用内存值，热返回与三十分钟新会话语义不变。WorkManager 的入队按代次记忆化：一次同意代次内不重复对同一唯一任务发起 IPC，仅在关闭统计取消任务后重新入队。
- 统计安装标识、会话及队列不参与云备份和设备迁移。

## 活跃与会话

ProcessLifecycleOwner 与实际 resumed Activity 同时满足，持续可见两秒或有明确功能操作才产生合格前台活动。后台进程创建不计入日活跃。热返回保留会话；离开三十分钟产生新会话。会话标识跨进程重启保存。持续前台跨北京时间午夜记录新日活动，事件时刻仍使用真实 UTC。

## 已接入业务边界

| 范围 | 观测方式 |
| --- | --- |
| 前台、会话、主要页面 | 生命周期资格判断；页面名固定枚举 |
| 课表导入、空教室查询 | ViewModel 启动与数据结果配对；Activity 重放不再新增终态 |
| 成绩、考试、学分查询 | 实际仓库调用的开始/终态；页面查看与查询分别记录 |
| 统一资源搜索 | 等待两路结果；区分成功、有结果、无结果与失败 |
| AI 文本/附件对话 | 每轮开始与正常返回结果配对 |
| ReAct 工具 | 每次执行开始/结束；返回字符串不能证明业务成功，记 unknown，抛出异常记失败或取消 |
| DeepSeek 请求 | 实际请求耗时、结果及返回的 Token 字段；缺失用量为 unknown，不造零 |
| 既有外观、公告等 | 保留原有调用点；不把目录存在视作完整接入 |

同步 ReAct 远程工具向 HITA 自有后端携带同一 operation_id，服务端按独立 attempt_id 记录执行。关联 ID 不含安装身份；统计关闭或同意代次改变后不再附加。跨域跳转会移除关联头，第三方模型及其他客户端不附加此头。异步脱离工具线程的请求尚未继承此关联。

事件及维度唯一目录为 data-backend 的 `services/hita-api/internal/telemetry/catalog.json`，本仓库 `app/src/main/assets/analytics-catalog-v2.json` 是其逐字节副本。新增事件先更新该目录，再同步客户端常量与实际调用点。运行时过滤未知维度和值；不能向统计接口发送任意字符串。

## 验证与边界

JDK 17 下执行 `:app:testDebugUnitTest :app:assembleDebug`。队列设备测试为 `cn.limpu.hita.data.analytics.UsageQueueInstrumentedTest`，覆盖落盘/重新打开/去重/租约/容量/过期/关闭统计；已在独立 Android 16 模拟器运行。另用实际 MainActivity 验证热返回、杀进程恢复、三十分钟离开、新会话及 UTC/test 环境，不借用用户原有虚拟设备。

尚未给目录内所有预留项接入业务：小组件点击、教师搜索/结果打开、成绩互助等不能视作已有完整观测。公告也尚未提供显示实例去重。对话取消若业务层未回调终态，后端会明确显示结果未知。Token 观测仅覆盖当前接入的 DeepSeek 路径；本地质量计数尚未汇总到远端。不能以此推算未启用统计者、全部客户端或供应商实际账单。

本次生成 Debug 测试包并保留现有正式版本号；不包含签名正式发布。新版留存需要实际上线后的时间窗口，历史旧事件不能补造为新版前台活动。
