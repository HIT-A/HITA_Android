## 实现

- 小字采用 11/16、12/16、13/18、14/20sp 成对字号/行高，继承主题字体和已有行高样式；没有显式行高样式时使用居中、不裁剪。课程进度条移除 Material3 的间隙和末端圆点。
- `MainBottomBarClearance` 统一悬浮底栏与胶囊底栏的高度和导航避让计算。读取 Compose 和根视图导航 inset 的较大值，并随根布局变化更新；主界面和今日页共用，删除今日页原来的 `+128.dp` 留白。
- `TodayLayoutPolicy` 仅按窗口尺寸、字号和底栏高度选择完整固定、紧凑固定或整页滚动模式；不依赖课程数量、来源状态或分钟刷新。
- 固定模式下问候和标题行固定，课程窗口独立滚动，考试/作业双摘要固定在底栏上方。课程窗口采用 16dp 离屏透明遮罩渐隐，保留现有主题背景。整页模式在空间不足时仍允许完整内容上下滚动。
- 摘要完整模式每行单行省略，紧凑模式保留来源标题、主值和一行状态；来源未就绪时紧凑作业卡优先展示该来源状态。未知计数使用破折号，只有已知空记录显示零。无课表时只显示作业卡；读取中及没有保留课程的失败状态显示等高占位。
- 今日页作业卡不再带单独重读按钮，整张卡复用原作业路由，重试在作业页进行。后台初次加载仍使用原有 HOMEWORK/GRADER 来源类型，因此没有删除这些枚举值。
- 默认显示所有未结束及时间无效的安排，已结束项折叠成“已结束 N 项”。全部结束时由完成卡负责展开历史；存在无效时间条目时，明日卡不重复完成计数，明日准备仍只出现一次。保留原 20:30 门槛。
- 点击课表名称打开完全展开的 `ModalBottomSheet`，列出单课表和课表组、当前勾选项及课表管理入口。长名称在面板中换行，胶囊内单行省略。
- 今日页与课表页统一按 `DisplayScope` 对象选择，当前选项不存在时拒绝操作；选择后沿用原持久化/联动更新并导航到目标周。ViewModel 在同一次 combine 中计算课表选项的勾选状态。
- 按课表和日期保存列表位置及历史展开状态。加载期间不挂载短占位列表，避免恢复的位置被列表范围截断；布局模式变化时回到顶部。

没有新增 Room 数据表、独立数据库、偏好设置或网络请求；考试统计仍为今天，作业沿用原来源和关联规则。
