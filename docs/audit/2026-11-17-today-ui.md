## 实现

- 新今日页替换旧大图布局：问候、当前/下一组状态与倒计时、来源明确的作业/考试文字摘要、接下来/全部安排、明日准备。未接入第二期摘要卡片与资讯入口。
- ViewModel 共用已有课表、作业、Grader 与考试读取链路，公开一个页面状态。读取失败与成功空表分开；同一查询失败可保留明确标记的本地记录。
- 作业来源分开呈现，未知不显示零；考试摘要限定当前课表并保留未知、未绑定及不完整覆盖提示，不承诺全量教务考试。
- 作息一致才推导饭点问候；当前/下一组不会被问候覆盖。重叠日程完整保留，已结束项仍保留时间、地点和点击详情。
- Fragment 只在 RESUMED 收集状态、加载本地记录并运行时钟。新状态会重算下一次唤醒时间，取分钟、有效事件起止、20:30 和午夜的最近边界；支持时间、日期和时区广播。隐藏页停止主动加载和时钟。
- 展开和列表位置使用以目标类型/ID、当地日期为键的 SaveableStateHolder；分钟变化不重置入场动画，成员变化沿用展开状态，日期变化恢复默认。
- 事件动作重新验证账号、会话、日期窗口、目标及成员，并按真实 ID 读取当前事件后打开详情。作业 Tab 可见时选择原 Tab，隐藏时使用内部 HomeworkActivity 复用 HomeworkFragment；考试、选表和导入沿用原入口。
- mini 课程条改为当前目标内当天范围的 IO 查询，按请求代次拒绝旧结果，成员变化触发刷新；继续只展示课程。
- 列表底部按现有底栏外边距及悬浮控件空间留白，使末项可滚出底栏覆盖区域。
- 小组件刷新按实际事件字段、目标与日期去重；分钟及摘要更新不触发刷新。
