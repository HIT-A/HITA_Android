# 今日课程卡片配色

## 调整

- 课程卡片、左侧色条、地点标签及进行中进度条使用同一课程色。已结束课程保留淡色底与色条，明日准备中的课程也显示色条；正文继续使用主题文字色。
- 课程颜色从所选课表的全量课程读取，复用 `TimetableColorAssigner` 稳定分配色槽，不按当天列表重新分配。颜色快照与事件共用课表、成员、日期查询身份，切换范围后取消旧订阅。
- 主题小色板无法容纳整张课表时，复用现有 16 色课程色板，保留用户选择的颜色预设及深浅模式，解决六色哈希造成的课程撞色。没有改写课程存储色或新增数据库表。
- 卡片主题边缘装饰也接收课程色；考试、待办摘要及导航布局保持原有组织。
