# 今日页考试统计范围修复与待办命名

## 真实问题

PJZ110 当前所选“深圳 2026秋季”课表包含两条可见考试记录：大学物理 XB（2026-10-31 14:00–15:00）已经结束，数字逻辑设计（2026-12-06 19:00–21:00）待参加。旧版只向今日页投影器传递今天和明天的事件，考试投影也只筛选当天，导致两条记录都未进入卡片，显示“0 场待参加 / 暂无考试记录”。

## 调整

- 今日页在同一 Room 查询快照中读取今日、明日安排及所选单课表或课表组的全部考试，继续应用隐藏、显示去重和账号来源规则。原有普通时间窗口查询默认行为保留；不改数据库结构。
- 考试摘要按结束时间分成待参加与已结束两组；最近考试跨日时显示日期。教务数据继续检查账号、会话和课表关联，并与已导入考试去重。
- 完整卡片显示待参加数量、最近考试日期时间、已结束数量；紧凑卡片保留待参加及已结束数量。卡片标题为“课表考试”。
- 今日课程列表和明日准备仍按原日期窗口投影。“今天还有 N 场考试”继续只计算当天，避免把未来考试作为今日提醒。
- “手写作业”改为“待办”，多来源摘要标题也统一为“待办”；保留现有本地与 Grader 路由。
- 同步修订 [固定摘要设计](../superpowers/specs/2026-11-18-today-fixed-summary-layout-design.md) 中原先限定为当天考试的规则。
