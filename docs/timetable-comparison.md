# 课表分享与双人对比

在课表主页点击“分享与好友”，可以打开“分享课表 / 生成口令”“导入口令”“好友课表”和“课表对比”。导入后确认保存好友，再选择自己的一份课表与一位好友开始对比。不会自动读取剪贴板。分享沿用已有口令和分享身份；对比本身不生成口令。

## 开启与退出

配置面板展示双方作息，只有节次数、顺序以及每节起止时间完全相同才能开启。学校或校区相同不代表兼容；缺失、无效或不同结构不能使用默认作息补齐或自动换算。结构不同仍可分享、导入和独立查看好友课表。

默认每日范围为 08:30–22:30，可调整为同一天内开始早于结束的范围，只纳入完整位于范围内的节次。范围没有完整节次时需要调整。共同无课与同节有课的显示开关独立控制。

开启后显示比较对象、图例、调整及“退出对比”。课程层只展示选定个人课表的课程；点击自己的课程可查看详情，网格点击及长按不会新增或编辑课程。点击比较区域，或打开“逐节详情与汇总”，可查看具体节次及每日统计。退出恢复普通课表的显示和编辑操作，不改变普通显示偏好。

切周按校园时区 Asia/Shanghai 的实际日期重新计算，不把双方各自的第 N 周直接配对。配置保存选定 ID、范围和开关，重建后重新读取数据。来源修改会重新计算；结构变得不兼容、读取失败或对象删除时隐藏旧结果并提示，不能把旧结果继续当作当前结果。

## 判定规则与限制

- 仅比较选定个人课表的课程（CLASS）及好友分享中的课程占用，不包含考试、个人活动或其他个人课表。“共同空闲”仅表示共同无课，不代表没有其他安排。
- 一个作息项就是一节，不自动拆成 45 分钟小节。默认六节为 08:30–10:15、10:30–12:15、14:00–15:45、16:00–17:45、18:45–20:30、20:45–22:30。午休和节间空档不生成比较区域，独立节次不跨休息时间合并。
- 课程与一节有任何正时长交叠，整节即有课；端点相接不算占用。双方这一节都无课显示绿色共同空闲，双方都有课显示红框同节有课，仅一方有课不计入这两类。
- 同节冲突不等于课程实际时间重叠。例如自己 08:30–09:00、好友 09:30–10:00，仍同占第一节。统计为完整节次数及完整节次时长，不是实际课程重叠时长。
- 整节必须完全落在双方有效期内才能判定；部分超出也整节标为未知，不能算空闲。有效期使用已有实际起止边界，不擅自延长结束时间。所有入选节次均未知时提示当前周不在双方共同有效期内。
- 作息外课程按原始时间展示，作息外部分不参与节次对照，也不生成额外节次。有效个人课表没有课程可以对比；非法记录或读取失败不能当作空课表。
- 支持完整课表和仅忙闲分享。仅忙闲好友只显示占用，不显示或推断课程名称、地点。比较结果不写入个人课程、日程或提醒，不创建分享身份，不改变 HITA1 协议和数据库版本。

分享、已保存好友读取和本地比较可以离线使用。好友数据是已保存快照，不是联网实时同步；好友的新安排需要重新导入更新。
