# HITA Android v3.2.0

## 新增

- 新增威海研究生教务支持：独立登录入口、课表、成绩、考试与培养方案，学期选项按研究生口径过滤；研究生选课支持动态类别与筛选条件。
- 新增 Grader 作业待办：自动导入作业与截止时间，已提交/已完成任务可折叠隐藏，完成状态按账号隔离保存在本机。
- 新增「网页登录态复用与静默续期」：登录成功即保存 cookie，冷启动发现会话过期时先用隐藏 WebView 静默重登一次，成功则直接加载课表，失败仍如实提示过期。
- 新增深圳 aTrust 自动登录：无感通过 aTrust 门户的「统一身份认证」，会话过期后同样可自动重登。
- 新增三校区账号密码保存与自动填充：登录成功后加密保存，再次登录自动填写并提交一次，免去重复输入。
- 新增底栏模块开关：待办、资讯、助手三个模块可独立开关，默认开启待办。
- 新增「更多功能」独立页，把原先堆在侧栏的功能拆分为独立入口。
- 新增四层测试体系：JVM 单元、仪器测试、性能专项与模拟机端到端流程，并附带统一的测试报告聚合脚本。
- 新增威海教务按网络环境自动选入口：校园网内直连教务系统，校外自动回落 WebVPN，校园网用户不再多走一次 VPN 认证。
- 新增三校区校园资讯：本部与威海接入各自的通知门户，深圳校园通知支持门户登录与多因子认证提示。

## 修复

- 修复深圳 aTrust 回跳后网页教务登录一直停在 Loading 的问题：aTrust 认证页曾被误判为「已连接」，导致门户与教务入口无限互相跳转。
- 修复本部研究生课表接口返回包装 JSON（`data` / `rows` / `content` / `result`）时被当成空课表的问题。
- 修复本部部分考试表格解析错误与考试导入时间校验问题。
- 修复升级安装后启动崩溃：重建课表分组索引，兼容诊断版遗留的不带反引号索引写法。
- 修复会话过期提示在静默续期未被宿主承接时，消耗掉一次性续期预算、导致后续不再自动重试的问题。
- 修复登录 WebView 可被任意页面劫持导航、忽略 SSL 错误的问题，改为按校区白名单校验主框架导航与弹窗。
- 修复加密存储不可用时 AI 设置回退明文保存的问题；改为进程内存储，并在历史明文迁移后删除旧文件。
- 修复登录页不勾选「N 天免登录」时身份票据为会话级 cookie、杀进程即失效的问题，改为自动勾选。
- 修复威海研究生登录被判「浏览器已过时」：教务请求补齐桌面浏览器标识，登录页不再被服务端拦下。
- 修复威海研究生登录点「关闭」后白屏：命中拦截页时退回登录入口重试，不再停在空白页。
- 修复课表「记住忽略」在会话过期重登后被清空：改为仅在退出登录或切换账号时清除，重登不再重复弹确认。
- 修复深圳校园通知首次登录被自动弹出：没有已保存账号时停在登录页等待输入，不再勾完「免登录」就退出。
- 修复退出深圳账号会清掉多因子设备信任、导致下次登录必须重新收验证码的问题。
- 修复未登录时「更多功能」页仍显示资讯入口、以及待办页评阅入口对非深圳账号可见的问题。

## 优化

- 移除统计客户端主线程同步写入磁盘、博客重试的阻塞等待，以及课程提醒与桌面组件的重复调度，后台任务收敛到单一来源。
- 收敛时间线、课表与课程浏览页的 UI 状态与重组开销，减少不必要的整表重算。
- 收紧文件共享与备份范围：FileProvider 只登记真实调用点目录，云备份与设备迁移排除凭据、AI Key、待办会话与 WebView cookie。
- 全局默认禁止明文 HTTP，改为按校园服务域名白名单放行；集中日志脱敏，登录相关日志不再输出 URL 参数、cookie 值与 token。
- 重构 CI：拆分仓库检查、JVM 测试、构建与设备测试四个并行门禁，第三方 Action 固定到 commit SHA，启用 Gradle 构建缓存并校验 wrapper 完整性。
- 优化登录流程：VPN 或信任门户连上后自动继续教务登录，不再停留在空白中转页；教务入口直接拉起网页登录，不再弹校区与账号选择。
- 优化课程浏览、成绩分析、培养方案等页面连上网页教务的入口，直接进入登录流程而不再多问一次校区。

待办、Grader 完成状态与登录凭据均只保存在本机，暂不支持云同步。威海校园网直连入口为本版新增，若所在网络不支持会自动回落 WebVPN。

GitHub 上的发布 tag 为 `v3.2.0-release`（仓库启用 immutable releases，`v3.2.0` 已被占用无法复用）；APK 内版本号仍是 3.2.0，应用内更新检查按正式版识别。
