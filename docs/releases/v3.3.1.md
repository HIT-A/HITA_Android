# HITA Android v3.3.1

## 新增

- 教务与校园数据支持本地缓存：实验中心、考试、成绩管理、个人成绩明细、空教室、培养方案与深圳课程浏览会先显示上一次成功的结果，再在后台刷新。

## 修复

- 修复考试查询与深圳课程浏览提示「学期列表解析失败」的问题：旧的校外代理地址已经转到 aTrust 网关，现在会自动改用直连并记住，不需要重新登录。
- 修复实验中心每次进入都要从头拉取整学期课表（实测 10 秒以上）的问题。
- 修复实验中心登录失效时整页被错误提示替换、看不到上次课表的问题。
- 修复成绩页只有学分绩汇总时，旧数据提示不出现的问题。

## 优化

- 刷新失败时页面顶部提示「刷新失败，正在显示某时某刻的数据」，可一键重试；实验中心登录失效时直接给出「去登录」。
- 教务与校园查询刷新失败不再静默：以前保留旧数据但没有任何说明，现在能明确知道看到的是旧数据。

缓存按登录账号隔离。纯蜂窝网络且没有校园网或 VPN 时，依赖深圳 Web 教务的页面会提示会话失效并引导重新登录，这是网络限制，不是数据损坏。

GitHub 上的发布 tag 为 `v3.3.1`，APK 内版本号与 tag 一致，应用内更新检查按正式版识别。
