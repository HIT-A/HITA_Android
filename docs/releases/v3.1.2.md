# HITA Android v3.1.2

## 新增

- 新增独立「待办」页，支持按日期安排作业、快速添加、编辑改期、完成撤销和每日完成进度；待办位于底部导航第一栏，更多位于最后一栏。

## 修复

- 修复本部部分考试分类查询与考试导入目标课表异常。
- 修复本部实验课短课程名称匹配错误，避免实验项目串到其他课程。
- 更新本部登录网关地址，修复登录后部分页面空白的问题。
- 修复部分课表修改、清空后被自动刷新恢复的问题，完善课表与课次数据保存。
- 修复课表分享超出所选课表日期范围的问题，课程提醒跟随当前显示课表。
- 改善手动检查更新按钮的可见性，修复部分深色模式文字对比度不足和研究生课表 HTML 字符显示异常。

## 优化

- 优化课表预览、学期切换及教务查询的状态管理与取消处理，改善页面切换和会话刷新时的稳定性。
- 优化 AI 助手任务取消、聊天附件处理与资源页面加载流程。
- 完善数据库升级与课表文件恢复机制，增强异常情况下的数据保留能力。

待办数据保存在本机；本版未加入待办云同步。
