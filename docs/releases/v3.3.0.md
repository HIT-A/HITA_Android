# HITA Android v3.3.0

## 新增

- 首页重新设计：教学周与星期作为主标题，正在上的课标注「进行中」并抬高卡片；当天的课全部结束后，首页直接显示明天的课程、考试与日程。
- 待办页改为统一面板：Grader 作业与本地待办按日期合并成一张清单，可登录 GeniusTA 自动导入各门课的截止时间，过期的导入项不再显示，平台登录与登出在页面内完成。
- 接入深圳校区校园服务：校园卡消费记录与余额、静音仓预约、图书馆研习间、实验室预约，登录态与本机记录分开保存。
- 课表支持查看课程版本与教务来源的变化，逐节对比后再决定是否采纳；误删的课程可以从工具栏历史里恢复。
- 新增下课前提醒与考试提醒，提醒规则可自行配置。
- 成绩页支持查看成绩分布；桌面小部件可自定义显示内容，课表可同步到系统日历。
- AI 助手在新增日程、提交课程资源等写操作前会先征求你的确认。
- 页面支持左右滑动切换；静音仓预约可选择起止时间、多人同行，取消时可填写理由。

## 修复

- 修复首页点击课程卡没有反应的问题，现在可以直接打开课程详情。
- 修复首页待办把已过期作业列出来的问题，改为只显示未截止的作业。
- 修复本部考试与成绩查询在会话过期后无法恢复的问题。
- 修复教务登录续期失败导致课表导入异常的问题。
- 修复暗色模式下部分文字与背景对比度过低的问题。
- 修复威海研究生登录的失败路径，以及静音仓登录页布局错位与鉴权失败的问题。
- 修复实验室预约登录时无法跳转学校统一认证的问题。
- 修复左右滑动切页松手回跳与卡顿的问题。
- 修复校园卡历史记录写入中断后数据不完整的问题。

## 优化

- 首页顶栏改为显示个人头像；课程卡标题单行显示、卡片高度统一，考试与待办卡片可以整块点击进入。
- 底栏「待办」与「时间表」的位置对调，常用入口更顺手。
- 首页的考试与待办摘要固定在不用滚动就能看到的位置。
- 待办与课表在两处入口的数据口径统一，勾选完成状态在本机按账号隔离保存。

校园卡、静音仓、图书馆与实验室四套服务目前只覆盖深圳校区，其余校区见到入口会提示暂不支持；待办、Grader 完成状态与登录凭据仍只保存在本机，不支持云同步。

GitHub 上的发布 tag 为 `v3.3.0`，APK 内版本号与 tag 一致，应用内更新检查按正式版识别。
